# MicroDatosIA - Microcredencial en IA con Python para Ciencia y Tecnología (I & II)
Modificado el 7 de octubre de 2026

## 📚 Resumen del Programa

Este repositorio contiene el material completo para la **Microcredencial en Programación Orientada a la Ciencia de Datos e Inteligencia Artificial en Ingeniería**. El curso está diseñado para proporcionar una base sólida en programación Python aplicada a problemas de ingeniería, ciencia de datos e inteligencia artificial.

## 🎯 Competencias Desarrolladas

- **Aprendizaje autónomo** - Capacidad de aprender y adaptarse a nuevas tecnologías
- **Programación en Python** - Dominio del lenguaje y sus librerías principales
- **Interpretación de datos** - Análisis crítico y extracción de insights
- **Visualización de datos** - Comunicación efectiva a través de gráficos
- **Resolución de problemas de ingeniería** - Aplicación práctica de herramientas de datos

## 🚀 Cómo Empezar

1. **Prerrequisitos**: Conocimientos básicos de matemáticas y lógica
2. **Configuración**: Instalar Python 3.11+ y Jupyter Notebook
3. **Orden recomendado**: Seguir la numeración de las carpetas (01 → 02 → 03 → 04 → etc)
4. **Cada módulo** contiene su propio README con instrucciones específicas

## 🛠️ Herramientas Utilizadas

- **Python 3.11+**
- **Jupyter Notebook**
- **Pandas** - Manipulación de datos
- **Matplotlib/Seaborn** - Visualización
- **NumPy** - Computación numérica
- **Scikit-learn** - Machine Learning
- **Visual Studio Code** - Entorno de desarrollo

## 🎓 Objetivos de Aprendizaje

Al completar este curso, serás capaz de:

- ✅ Comprender los fundamentos de la ciencia de datos y la IA para resolver problemas de ingeniería
- ✅ Familiarizarte con el entorno de desarrollo Visual Studio Code
- ✅ Implementar buenas prácticas de codificación en Python
- ✅ Estructurar problemas de ingeniería desde una perspectiva de ciencia de datos
- ✅ Adquirir habilidades para la limpieza, procesamiento y visualización de datos
- ✅ Integrar herramientas de IA en el proceso de programación para aumentar la eficiencia

## 📝 Contenidos Específicos

- Cómo abordar problemas de ingeniería utilizando herramientas y técnicas de análisis de datos
- Desarrollo de habilidades en programación con Python aplicando buenas prácticas
- Instalación y uso del entorno Visual Studio Code para Python
- Programación con Python en entornos interactivos como Jupyter Notebook
- Incorporación de herramientas de IA como GitHub Copilot en el proceso de programación
- Limpieza, procesamiento y visualización de datos con Python y VS Code
